# AI 思維顧問團

一個免安裝、單檔的網頁工具：從 12 個虛構的思考角色中挑選一位或多位「思維顧問」，針對人生規劃、工作任務、工作計畫等問題提問，被選中的角色各自以其觀點獨立回覆、並列呈現，方便你比較不同視角。

**線上體驗**：<https://m255525.github.io/mentors-panel/>

## 12 個思考角色

- **穩健投資人**：先看值不值得、會不會賠掉本金，再談報酬
- **紀律執行主管**：把目標拆成流程、責任與檢查點
- **原創混搭創作者**：找沒人做過的組合，用作品說話
- **極簡產品設計者**：刪到只剩真正重要的功能與體驗
- **顧客價值行銷顧問**：先分清楚服務誰、提供什麼價值，再談推廣
- **風格策展人**：用一致的風格和取捨建立辨識度
- **技術現況判讀者**：分清楚展示、可用與可靠之間的差距
- **大膽願景家**：先想十年後的樣子，再回推今天的第一步
- **故事敘事者**：用人物、衝突與轉折讓人記住
- **人際溝通教練**：先理解對方在意什麼，再談自己的要求
- **現金流管家**：先確認活得下去，再談成長
- **反方檢查員**：專門找漏洞、盲點與沒驗證的假設

角色全部虛構、內容自行撰寫，**不代表任何真實人物**，也不使用真實人物的姓名、語錄或生平。

## 怎麼使用

1. 用瀏覽器直接開啟 `index.html`，或到部署好的網址使用。
2. 準備一把你自己的 LLM API 金鑰（Claude / OpenAI / Gemini / OpenRouter 任選一家）。
3. 點右上角「⚙ API 設定」填入金鑰——**金鑰只存在你自己瀏覽器的 localStorage，不會經過任何伺服器，本站開發者無法取得**。
4. 勾選一位或多位顧問、輸入問題、送出。
5. 回覆若因長度限制被截斷，卡片會出現「接續完整回覆」按鈕，可以接續生成、內容會自然銜接。
6. 對話紀錄可以隨時「⬇ 下載txt」保存，或「🗑 清除對話」重新開始。

## 技術重點

純前端靜態網站（HTML/CSS/JS，無框架、無建置步驟），LLM API 由瀏覽器直接呼叫官方端點。角色資料在 `personas-data.js`。詳見 `CLAUDE.md`。
