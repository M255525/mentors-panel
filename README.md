# AI人物顧問團

一個免安裝、單檔的網頁工具：從7位公眾人物中挑選一位或多位「思維顧問」，針對人生規劃、工作任務、工作計畫等問題提問，被選中的角色各自以其思維框架獨立回覆、並列呈現，方便你比較不同視角。

**線上體驗**：<https://m255525.github.io/mentors-panel/>

## 7位顧問

黃仁勳、郭台銘、周杰倫、賈伯斯、菲利浦．科特勒、可可．香奈兒、安德烈．卡帕西——每位角色的思維框架都是AI根據其公開演講、訪談、著作與媒體報導整理出的框架推斷，**不代表本人真實立場、觀點或授權**，僅供啟發與練習用途參考。詳見網站內建的「操作手冊」與各角色的免責聲明。

## 怎麼使用

1. 用瀏覽器直接開啟 `index.html`，或到部署好的網址使用。
2. 準備一把你自己的 LLM API 金鑰（Claude / OpenAI / Gemini / OpenRouter 任選一家）。
3. 點右上角「⚙ API 設定」填入金鑰——**金鑰只存在你自己瀏覽器的 localStorage，不會經過任何伺服器，本站開發者無法取得**。
4. 勾選一位或多位顧問、輸入問題、送出。

## 技術重點

純前端靜態網站（HTML/CSS/JS，無框架、無建置步驟），LLM API 由瀏覽器直接呼叫官方端點。人物思維框架資料由 `scripts/build_personas.py` 從 [nuwa-skill](https://github.com/alchaincyf/nuwa-skill) 蒸餾出的人物 Skill 轉換而成。詳見 `CLAUDE.md`。
