這是什麼網站？

一個單檔、免安裝的網頁工具：你可以從12位公眾人物中選擇一位或多位「思維顧問」，針對人生規劃、工作任務、工作計畫等問題提問，被選中的角色會各自以其思維框架獨立回覆，並列呈現方便你比較不同視角。

用瀏覽器打開 index.html 即可使用，不需要架伺服器、不需要安裝任何軟體，桌機/平板/手機都能開啟。

怎麼開始使用

  1. 準備一把你自己的LLM API金鑰（Claude、OpenAI、Gemini、OpenRouter 任選一家，擇一即可）。
  2. 點右上角「⚙ API 設定」，選服務商、貼上金鑰、按儲存。
  3. 在「選擇顧問」區勾選一位或多位人物——第一次選某位角色時，會先彈出一次性的完整說明，請詳讀後按「我瞭解了」。
  4. 在輸入框打字提問（或點下方「人生規劃／工作任務／工作計畫」快速範例填入），按「送出問題」。
  5. 被選中的每一位角色會各自獨立生成回覆，並列顯示成卡片；同一位角色的多輪對話會記得自己之前說過什麼，但看不到其他角色的回覆。
💡 卡片上ⓘ圖示可以隨時重新查看該角色的完整說明與免責聲明，不限第一次選取時。

API 金鑰去哪裡拿？會不會外洩？

四家服務商任選一家申請即可（各家都有免費額度或需自行儲值，費用由你直接支付給該服務商，本站不經手）：

  • Claude（Anthropic）：console.anthropic.com
  • OpenAI：platform.openai.com
  • Gemini（Google AI Studio）：aistudio.google.com
  • OpenRouter：openrouter.ai（可用單一金鑰呼叫多家模型）

金鑰只會存在你目前使用的這個瀏覽器（localStorage），網頁程式碼會直接從你的瀏覽器連到該服務商的官方伺服器，不會經過本站或任何第三方伺服器中繼，本站開發者也無法看到或取得你的金鑰。換瀏覽器、換裝置或清除瀏覽資料後，需要重新輸入一次金鑰。請避免在公用電腦上填寫金鑰。

常見問題

為什麼送出問題後沒有反應？

檢查是否已經在「⚙ API 設定」填入金鑰；也可能是金鑰無效或額度不足，回覆卡片會顯示錯誤訊息與「重試」按鈕。

一次選很多位顧問會比較貴嗎？

會——每多選一位，就會多打一次API請求，費用依你選用的服務商計費規則而定，與本站無關。建議先選2~3位測試。

可以問任何問題嗎？

可以，但每位角色都有各自的「誠實邊界」——遇到本人從未公開表態過的領域，角色會標註「這是框架推斷，非本人真實立場」而非憑空捏造答案。
